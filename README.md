## Как собрать APK (по шагам)
1. На GitHub: **+ → New repository**, имя `kingdoms`, Create.
2. **uploading an existing file** → перетащи ВСЕ файлы и папки из распакованного архива (www, resources, package.json, capacitor.config.json, privacy.html, .gitignore, README.md) → Commit changes.
3. Папка `.github` при перетаскивании часто теряется. Создай файл вручную: **Add file → Create new file**, имя `.github/workflows/build-apk.yml`, вставь содержимое из архива, Commit.
4. Вкладка **Actions** → дождись зелёной галочки (5–10 минут).
5. Открой завершённый запуск → внизу **Artifacts → Kingdoms-APK** → скачай, распакуй, установи `app-debug.apk` на телефон.

## Политика конфиденциальности (ссылка)
Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
Через минуту будет: `https://ТВОЙ_НИК.github.io/kingdoms/privacy.html`
